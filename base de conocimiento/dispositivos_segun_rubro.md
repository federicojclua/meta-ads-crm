## Criterio general

**Mostrador fijo + impresión de comprobantes** → **Clover Mini**.

**Movilidad dentro o fuera del local + impresión** → **Clover Flex**.

**Movilidad máxima + comprobantes 100% digitales** → **Clover Flex Pocket**.

**Autoservicio + alto flujo + reducción de filas** → **Clover Kiosk**.

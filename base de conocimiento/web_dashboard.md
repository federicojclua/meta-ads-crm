## Qué es

Web Dashboard es la plataforma web de Clover para gestionar el negocio en forma remota. Permite acceder a información de transacciones, reportes y configuración de los dispositivos Clover desde cualquier lugar, en tiempo real.

## Funcionalidades principales

### Gestión de transacciones
Consolidación de operaciones de todos los terminales del comercio en una sola vista. Se puede ver ventas por vendedor y obtener datos consolidados del flujo comercial.

### Administración de empleados
Permite administrar los fichajes de empleados, controlar asistencia y desempeño individual.

### Configuración remota
Configurar dispositivos Clover a distancia, sin necesidad de acceso físico.

### Mi cuenta
Gestión personal: preferencias, accesos, datos de comerciante.

## Características destacadas

- Información en tiempo real del desempeño del negocio.
- Múltiples puntos de cobro simplificados en una sola interfaz.
- Acceso desde cualquier dispositivo con conexión a internet.

## Seguridad

A partir de marzo, la **autenticación de dos factores (2FA) es obligatoria**: el sistema envía un código por SMS al teléfono registrado en cada inicio de sesión.

## Relación con POSBerry

Web Dashboard de Clover es complementario, no sustituto, de POSBerry. El comercio puede usar ambos:
- **Clover Web Dashboard**: vista de transacciones de cobro y configuración de dispositivos Clover.
- **POSBerry web/app**: gestión comercial completa (productos, stock, ventas, comprobantes, recetas, reportes por rubro).

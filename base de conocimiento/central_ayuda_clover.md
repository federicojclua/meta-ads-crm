## Categorías principales

### Dispositivos
- **Clover Flex**: dispositivo inteligente transportable con impresora.
- **Clover Mini**: solución de mostrador para transacciones simplificadas.
- **Clover Flex Pocket**: alternativa portátil y sin impresora.
- **Clover Kiosk**: sistema para pedidos ágiles en autoservicio.

### Aplicaciones
- **Web Dashboard**: visualización en tiempo real de transacciones y control remoto.
- **Express POS**: aplicación de gestión comercial nativa de Fiserv. *(Para este asistente: ver carpeta 09_competencia.)*

### Funcionalidades de pago
- Cobranza con tarjeta (banda magnética, chip, contactless).
- Pagos con QR.
- Pagos con Pix (turistas brasileños).
- Propinas digitales.
- Pagos divididos.

### Gestión operativa
- **App Ventas**: procesamiento de pagos múltiples.
- **App Transacciones**: anulaciones y devoluciones.
- **Autorizaciones**: pre-autorizaciones y confirmaciones.
- **Configuración**: personalización de números comerciales.

### Soporte técnico
- Conectividad Wi-Fi y 4G/5G.
- Carga de batería.
- Recuperación de contraseñas.
- Diagnóstico desde la app **Ayuda** del dispositivo.
